# Electricity Usage Tracker

برنامج بلغة C++ يعمل من التيرمنال، لتتبع استهلاك الكهرباء الشهري وتحليله.

## المميزات
- تخزين قراءات الاستهلاك لـ 12 شهر في مصفوفة.
- حساب الإجمالي والمتوسط.
- تحديد أعلى شهر وأقل شهر استهلاكاً.
- إدخال قراءات جديدة مع التحقق من المدخلات.
- حفظ التقرير في ملف `report.txt`.
- عرض القراءات مرتبة من الأقل إلى الأعلى.
- تحليل الشهور التي تجاوز استهلاكها حداً يحدده المستخدم.

## طريقة التشغيل

على لينكس أو ماك:

```bash
g++ main.cpp -o program
./program
```

على ويندوز:

```bash
g++ main.cpp -o program
.\program.exe
```

## القائمة

| الخيار | الوظيفة |
|--------|---------|
| 1 | إجمالي الاستهلاك |
| 2 | متوسط الاستهلاك |
| 3 | أعلى شهر |
| 4 | أقل شهر |
| 5 | إدخال قراءات جديدة |
| 6 | حفظ التقرير في ملف |
| 7 | عرض القراءات مرتبة |
| 8 | تحليل الحد (Threshold) |
| 0 | خروج |

## الدوال المستخدمة
- `totalUsage`: تحسب الإجمالي.
- `averageUsage`: تحسب المتوسط.
- `maxMonth` / `minMonth`: ترجع فهرس أعلى وأقل شهر.
- `readPositive`: تقرأ رقم موجب وتتحقق منه.
- `readChoice`: تقرأ اختيار القائمة وتتحقق منه.
- `enterReadings`: تدخل قراءات كل الشهور.
- `showSorted`: ترتب نسخة من القراءات بطريقة Bubble Sort وتعرضها.
- `thresholdAnalysis`: تعرض الشهور التي تجاوزت الحد المدخل.
- `saveReport`: تكتب التقرير في ملف.

## الملفات
- `main.cpp`: الكود المصدري.
- `report.txt`: التقرير المحفوظ (يُنشأ بعد الخيار 6).
