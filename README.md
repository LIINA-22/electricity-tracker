# Electricity Usage Tracker

برنامج بلغة C++ يعمل من التيرمنال، لتتبع استهلاك الكهرباء الشهري وتحليله.

## المميزات
- تخزين قراءات الاستهلاك لـ 12 شهر في مصفوفة.
- حساب الإجمالي والمتوسط.
- تحديد أعلى شهر وأقل شهر استهلاكاً.
- إدخال قراءات جديدة مع التحقق من المدخلات.
- حفظ التقرير في ملف `report.txt`.

## طريقة التشغيل

على لينكس أو ماك:

```bash
g++ main.cpp -o program
./program
```

على ويندوز:

```bash
g++ main.cpp -o program
.\program.exe
```
